# Date-Time-Overlay

I often get so immersed in games that I lose track of time.

Sometimes I wonder what time it is, but I can't see a clock anywhere on the screen.

So, I created a simple time overlay program that displays the current time directly on your screen while you play.

If you like my program and find it useful.
